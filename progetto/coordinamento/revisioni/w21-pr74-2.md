| Caso verificato | Esito |
|---|---|
| Apertura con entrambe le settimane adiacenti disponibili | Tre `getWeek`: settimana mostrata e due vicine. |
| Cambio del solo giorno | Nessuna lettura aggiuntiva. |

| Riconnessione, dopo letture completate | Una lettura aggiuntiva, della settimana mostrata. |
| Invalidazione delle query Menu | Si rilegge soltanto la settimana mostrata. |
| Selezione di una settimana letta in anticipo | La normale query ne ricontrolla la versione, inviando `knownVersion`. |
| Copia anticipata vecchia e risposta aggiornata ritardata | La copia resta visibile; stessa striscia DOM, ricentrata al cambio delle date, nessun «Caricamento…». La risposta aggiorna i pasti senza cambiare giorno. |
| Offline con copia anticipata disponibile | Arrivo immediato; controllo della versione alla riconnessione. |
| Prefetch fallito, selezione offline senza copia | «Caricamento…», poi arrivo corretto alla riconnessione. |
| Prefetch lento | Attesa come dal calendario; alla risposta nessuna trasformazione residua. |
| Prefetch fallito e successiva lettura fallita | Compare «Riprova»; il tentativo successivo recupera la settimana. |
