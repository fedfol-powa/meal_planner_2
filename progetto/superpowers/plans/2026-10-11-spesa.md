# Spesa, anche offline: piano di implementazione

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** lista della spesa della settimana dai dati veri, condivisa, modificabile anche
offline, esportabile come testo e verso Bring!, con gli stessi contenuti via MCP.

**Architecture:** operazioni dell'area `shopping` nel contratto (oRPC, zod) con la vista
già pronta; gestori nel Worker che leggono settimana, versioni delle ricette (R1, di
W1) e catalogo nella transazione dell'utente e usano il dominio puro
`domain/src/shopping/`; pagina pubblica di Bring! nel ruolo `anon`; nel web una coda
per utente in IndexedDB per tutte le modifiche della lista, mostrata come strato «da
sincronizzare» sopra la vista in cache.

**Tech Stack:** TypeScript, zod 4, oRPC 1.15, Postgres.js, Vitest, React con TanStack
Query (base di W5). Nessuna dipendenza nuova.

**Spec:** `progetto/superpowers/specs/2026-10-11-spesa.md` (da leggere prima di ogni
task), specifica principale sezioni 1, 6, 12, 13.

## Global Constraints

- Codice, identificatori, commenti e test in inglese; documenti e commit in italiano.
- Testi per l'utente in `it-IT` e `en-GB`, mai cablati nei componenti.
- Nessuna dipendenza esterna nuova; `contract` dipende da `@app/domain` (workspace).
- Nessuna migrazione e nessuna modifica di tabelle.
- Ogni operazione `offline` ha `id` uuid nell'input (`checkContract`), stato assoluto.
- `setItemChecked` con `checked: true` porta sempre `quantityAtCheck`; il server non la
  ricava mai.
- Nessun cast per far passare il typecheck: l'area si registra nel contratto globale e
  nel router solo quando tutti i gestori esistono (task 5).
- Nessun aggiornamento ottimistico: la cache delle query riceve solo risposte del server;
  le modifiche in coda vivono nello strato «da sincronizzare».
- File condivisi (indice del contratto, router, `app.ts`, rotte web, Menu, dizionari
  comuni) toccati solo per registrare l'area, con modifiche minime.
- Testo delle voci libere: spazi compattati, da 1 a 60 caratteri.
- Pagina Bring!: `noindex`, `Cache-Control: no-store`, nome della Recipe «Cosa si mangia».
- Comandi: `npm test -w <pacchetto>`, `npm run typecheck`; i test del server con
  database richiedono `TEST_DATABASE_URL` (stack locale `supabase db start`).

```ts
// contract/src/shopping/view.ts
import { departmentSchema } from '@app/domain/shopping';
import { combinedQuantitySchema, MEASUREMENT_SYSTEMS } from '@app/domain/units';
import { z } from 'zod';
import { localeSchema } from '../locale.ts';

export const isoDate = z.iso.date();
/** A Monday, as the list route `/shopping/<monday>`. */
export const mondaySchema = isoDate.refine((d) => new Date(`${d}T00:00:00Z`).getUTCDay() === 1, { message: 'not_monday' });

const sourceView = z.object({
	slotId: z.uuid(), date: isoDate, mealType: z.enum(['lunch', 'dinner']), recipeName: z.string(), quantity: z.string(),
});
export const shoppingItemViewSchema = z.object({
	key: z.string(), ingredientId: z.uuid(), varietyKey: z.string(), department: departmentSchema,
	name: z.string(), quantity: z.string(), combined: combinedQuantitySchema, isOptional: z.boolean(),
	excluded: z.enum(['avoid', 'pantry']).nullable(), checked: z.boolean(), previousQuantity: z.string().nullable(),
	sources: z.array(sourceView),
});
export const freeItemViewSchema = z.object({ id: z.uuid(), text: z.string(), checked: z.boolean() });
export const shoppingListViewSchema = z.object({
	weekStartsOn: isoDate,
	locale: localeSchema,
	/** The family's system: the web formats «prima: …» in the pending layer with it. */
	measurementSystem: z.enum(MEASUREMENT_SYSTEMS),
	mealCount: z.number().int().nonnegative(),
	departments: z.array(z.object({ department: departmentSchema, items: z.array(shoppingItemViewSchema) })),
	excluded: z.array(shoppingItemViewSchema),
	/** Meals left out: recipes without ingredients and never-published recipes (name null when not readable). */
	skipped: z.array(z.object({ slotId: z.uuid(), recipeId: z.uuid(), recipeName: z.string().nullable() })),
	freeItems: z.array(freeItemViewSchema),
	/** name null: the author is no longer a member. */
	lastChange: z.object({ name: z.string().nullable(), at: z.iso.datetime({ offset: true }) }).nullable(),
});
export type ShoppingListView = z.infer<typeof shoppingListViewSchema>;
export type ShoppingItemView = z.infer<typeof shoppingItemViewSchema>;

export const MAX_FREE_ITEM_TEXT = 60;
/** Trimmed, inner spaces collapsed; null when empty or too long. */
export function normalizeFreeItemText(text: string): string | null {
	const clean = text.trim().replace(/\s+/g, ' ');
	return clean.length >= 1 && clean.length <= MAX_FREE_ITEM_TEXT ? clean : null;
}
```

```ts
// contract/src/shopping/operations.ts
import { combinedQuantitySchema } from '@app/domain/units';
import { z } from 'zod';
import { errorDefinitions } from '../errors.ts';
import { op } from '../op.ts';
import { versionedInput, versionedOutput } from '../versioned.ts';
import { MAX_FREE_ITEM_TEXT, mondaySchema, shoppingListViewSchema } from './view.ts';

const week = z.object({ familyId: z.uuid(), weekStartsOn: mondaySchema });
const edit = week.extend({ id: z.uuid() });
const item = { ingredientId: z.uuid(), varietyKey: z.string().max(200) };
/** Mutations answer with the updated view and its version (W5's mutation model). */
const updated = z.object({ version: z.string(), data: shoppingListViewSchema });
const found = { not_found: errorDefinitions.not_found };
const write = { mcp: { readOnly: false }, offline: true, role: 'familyMember' } as const;

export const shoppingContract = { shopping: {
	getWeekList: op({ mcp: { readOnly: true }, offline: false, role: 'familyMember', reads: ['family', 'catalogue'] })
		.route({ method: 'GET', path: '/shopping/week-list', summary: 'Shopping list of a week, ready to show' })
		.errors(found).input(versionedInput(week)).output(versionedOutput(shoppingListViewSchema)),
	setItemChecked: op(write)
		.route({ method: 'POST', path: '/shopping/set-item-checked', summary: 'Tick or untick an item (absolute state)' })
		.errors(found)
		.input(
			edit
				.extend({ ...item, checked: z.boolean(), quantityAtCheck: combinedQuantitySchema.optional() })
				// Ticking always carries the quantity seen: a repeated request saves the same content.
				.refine((v) => v.checked === (v.quantityAtCheck !== undefined), { path: ['quantityAtCheck'], message: 'quantity_at_check' }),
		)
		.output(updated),
	setAddedBack: op(write)
		.route({ method: 'POST', path: '/shopping/set-added-back', summary: 'Put a pantry or avoided item back on the list, or take it off' })
		.errors(found).input(edit.extend({ ...item, addedBack: z.boolean() })).output(updated),
	addFreeItem: op({ ...write, creates: true })
		.route({ method: 'POST', path: '/shopping/add-free-item', summary: 'Add a free item; id is the new item id' })
		.errors(found).input(edit.extend({ text: z.string().max(MAX_FREE_ITEM_TEXT * 4) })).output(updated),
	setFreeItemChecked: op(write)
		.route({ method: 'POST', path: '/shopping/set-free-item-checked', summary: 'Tick or untick a free item' })
		.errors(found).input(edit.extend({ itemId: z.uuid(), checked: z.boolean() })).output(updated),
	removeFreeItem: op(write)
		.route({ method: 'POST', path: '/shopping/remove-free-item', summary: 'Remove a free item; removing it twice is fine' })
		.errors(found).input(edit.extend({ itemId: z.uuid() })).output(updated),
	exportList: op({ mcp: { readOnly: true }, offline: false, role: 'familyMember' })
		.route({ method: 'GET', path: '/shopping/export', summary: 'Plain text of the list, ticked items left out' })
		.errors(found).input(week).output(z.object({ text: z.string(), lines: z.array(z.string()) })),
	createBringLink: op({ mcp: { readOnly: false }, offline: false, role: 'familyMember' })
		.route({ method: 'POST', path: '/shopping/bring-link', summary: 'Link that opens the list in Bring! (30 minutes)' })
		.errors(found).input(week).output(z.object({ url: z.url(), expiresAt: z.iso.datetime({ offset: true }) })),
} };
```

  `read.ts`:

```ts
export async function findWeek(tx: Tx, familyId: string, weekStartsOn: string) {
	const rows = await tx<{ id: string }[]>`select id from app.weeks where family_id = ${familyId} and starts_on = ${weekStartsOn}`;
	if (!rows[0]) throw appError('not_found');
	return { weekId: rows[0].id };
}

export async function readListView(tx: Tx, deps: ShoppingDeps, input: ListInput): Promise<ShoppingListView> {
	const { weekId } = await findWeek(tx, input.familyId, input.weekStartsOn);
	const consolidated = await consolidatedList(tx, deps, input.familyId, weekId);
	const list = await listRow(tx, input.familyId, weekId); // {id, updatedBy, updatedAt} | null
	const [checks, addedBack, freeItems] = list ? await listState(tx, list.id) : [[], [], []];
	const family = await tx<{ system: MeasurementSystem }[]>`select measurement_system as system from app.families where id = ${input.familyId}`;
	const arranged = arrangeShoppingList(consolidated, { checks, addedBack, system: family[0]!.system, locale: input.locale });
	return {
		weekStartsOn: input.weekStartsOn, measurementSystem: family[0]!.system, ...arranged, freeItems,
		skipped: [...arranged.skipped, ...unpublishedSkipped],
		lastChange: list ? { name: await memberName(tx, input.familyId, list.updatedBy), at: list.updatedAt.toISOString() } : null,
	};
}
```

  `consolidatedList` legge slot e servings della settimana, chiama
  `deps.mealRecipeVersions`, `loadRecipes`, gli ingredienti citati
  (`select id, name, department, is_pantry from app.ingredients where id = any(...)`),
  le equivalenze `scope = 'shopping'` di quegli ingredienti (mappate su

  (`{slotId, recipeId, recipeName}`), aggiunta dopo quelle del dominio; il nome si legge

  la riga può non essere visibile ai membri, e allora `recipeName` è null).
